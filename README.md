# 🌦️ Weather App

A responsive **Weather App** built using **HTML**, **CSS**, and **JavaScript** that provides current weather information for any city in the world using live weather data fetched from a weather API.

## 🧩 Features

- Get current weather based on city name
- Displays temperature, humidity, wind speed, and weather condition
- Input field with search button
- Fully responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- weather API
